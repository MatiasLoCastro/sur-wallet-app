# sur-wallet-app
Kotlin app

A simple Kotlin-based Android application that simulates a virtual wallet. Built using **Jetpack Compose**, this app allows users to manage their profile, cards, digital account, and track transactions with a clean and responsive UI.

---

## 🚀 Features

- 👤 User Profile (name, preferences, light/dark mode)
- 💳 Card Management (add, view, remove cards)
- 🔁 Transaction History (filter by date and type)
- 🧾 Digital Account Summary (balance, movements)
- 🚍 Load Sube Card (simulated operation)
- 🌗 Light/Dark Mode Toggle

---

## 🛠 Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **MVVM Architecture**
- **Firebase**
- **Hilt (dependency injection)**
